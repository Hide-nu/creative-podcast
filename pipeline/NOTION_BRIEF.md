# Notion書き込みブリーフ

各エピソード <b>（例：1005_月_ダムウェイズトゥダイ）について、以下を行う。

1. `/root/pod/meta/<b>.json` を読み、page_id / award / note を得る。
2. `/root/pod/notion/<b>.md` を読む（台本全文＋出典トグル。Notion-flavored Markdown 済み）。
3. ページを `notion-fetch` で取得し、現在の本文と プロパティ（メモ、受賞年）を確認する。
   - 本文が空（blank page）の場合のみ、`notion-update-page` の `insert_content`（position は省略=末尾）で md の中身を**一字一句そのまま**入れる。本文に既に台本がある場合は入れない（二重になるため）。音声ブロックだけがある場合は末尾に入れてよい。
   - 大きすぎて失敗したら、md を行の区切りで2つに分けて2回に分けて末尾に追加する（出典トグルは必ず最後）。
4. `update_properties` で次を設定：
   - "ステータス": "台本済み"
   - "確認状況": "確認済み"
   - "受賞年": 現在空なら award を入れる（既に値があればそのまま）
   - note が空でない場合のみ "メモ": 既存のメモ + "／確認メモ：" + note（既存メモが空なら "確認メモ：" + note）。noteは長ければ200字程度に要約してよい。
5. 最後に1回 fetch し、本文の先頭行が「おはようございます。」で始まり、出典トグルが末尾にあり、台本が二重になっていないことを確認する。

他のページやデータベースには触れない。音声の貼り付けはしない（別工程）。
終わったら、各エピソード1行で結果を返す。
